# Global Logistics & Transportation System - Angular Framework

Este proyecto es una arquitectura/framework frontend desarrollada en **Angular (TypeScript / HTML / CSS)** para un Sistema Global de Logística y Transporte Internacional.

## 📦 Estructura del Proyecto

```text
global-logistics-system/
├── src/
│   ├── app/
│   │   ├── models/
│   │   │   └── logistics.model.ts      # Interfaces para Envíos, Rutas y Flota
│   │   ├── services/
│   │   │   └── logistics.service.ts    # Servicio centralizado de datos y APIs de transporte
│   │   ├── components/
│   │   │   └── dashboard/              # Panel de control ejecutivo y monitoreo en tiempo real
│   │   └── app.module.ts               # Módulo principal de Angular
```

## 🚀 Requisitos e Instalación

1. Tener instalado **Node.js** (v16 o superior) y **Angular CLI**.
2. Clonar/Descomprimir este proyecto en tu entorno local.
3. Ejecutar los siguientes comandos en la terminal:

```bash
npm install
ng serve
```

4. Navega a `http://localhost:4200/` para ver la aplicación ejecutándose.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** TypeScript (Frontend SPA Framework)
- **Framework:** Angular
- **Estilos:** CSS3 / Grid & Flexbox responsive design
